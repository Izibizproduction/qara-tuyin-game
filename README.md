# Qara Tuyin («Қара Түйін») — сборка для публикации

Казахстанская версия игры: премьера 5 ноября 2026, языки RU / KK,
билеты — казахстанские кинотеатры.

В этой папке лежит всё, что нужно выложить на хостинг:

```
dist/
  index.html          ← вся игра: разметка, стили и код в одном файле (62 КБ)
  assets/             ← пережатые картинки, QR и музыка
```

Больше ничего копировать не нужно. Папки `assets/` и `tools/` уровнем выше —
это исходники и сборщик, они на сервер не выкладываются.

## Проверить локально

```bash
cd dist && python -m http.server 8000
```

Открыть `http://localhost:8000`. Просто двойным щелчком по `index.html`
запускать нельзя: браузер по протоколу `file://` запрещает читать картинки
через canvas, и постер результата не соберётся.

## Что делать, когда пришлёте новые арты

1. Положить PNG в `assets/characters/` уровнем выше (не в `dist/`):
   - `asan_caught.png`, `asel_caught.png` — цельная сцена «ведьма схватила
     ребёнка» (обе фигуры в одной картинке). Ставится на постер результата
     одной композицией, когда забег закончился поимкой. Прозрачные поля вокруг
     фигур сборщик обрежет сам;
   - `witch_scare.png` — готовое крупное лицо для скримера. Если его положить,
     оно заменит то, что сейчас собирается автоматически кадрированием
     `witch_face.png`.

   Отдельная бегущая ведьма (`witch_run.png`) больше не нужна: она требовалась,
   пока постер собирался из двух отдельных фигур.
2. Выполнить из корня проекта:

```bash
python tools/build_assets.py
```

Скрипт сам пережмёт новые файлы, обновит `dist/assets/manifest.json` и игра
подхватит арты без единой правки в коде.

## Как поднять хостинг заново

Двойной щелчок по `tools\start_hosting.cmd`. Скрипт поднимает локальный сервер
и туннель Cloudflare, а в окне печатает публичный адрес вида
`https://xxx-xxx-xxx.trycloudflare.com` — его и отправляйте коллегам.

Пока окно открыто, игра доступна из любой точки. Закрыли окно или выключили
компьютер — ссылка перестаёт работать. **При каждом запуске адрес новый.**

## Как устроена игра (главное правило)

**Любая собранная тройка проламывает один блок на пути ребёнка.** Игроку не
нужно выцеливать конкретные предметы перед ребёнком — достаточно собирать где
угодно, и он идёт дальше. Комбо ломает несколько блоков подряд. Благодаря
этому связь «я собрал — ребёнок пошёл» видна сразу, и безвыходных ситуаций
не бывает: если валидного хода на поле не осталось, обереги смещаются сами.

Ходят герои только по четырём сторонам (без диагоналей) — иначе путь до двери
выходит вдвое короче и ведьма не успевает создать напряжение.

Сложность крутится двумя строками в функции `cfg()`:

```js
approach: Math.max(4, 8.5 - 0.5 * (lv - 1)),   // сек, пока ведьма идёт по дороге
hunt:     Math.min(140, 72 + 9 * (lv - 1))     // скорость погони в доме
```

## Языки

RU / KK. Основной — русский, он же по умолчанию; казахский включается сам,
если телефон на казахском (`kk`/`kaz` в `navigator.languages`). Ручной выбор
запоминается. Все тексты — в объекте `I18N` в начале скрипта.

**Казахский перевод не вычитан носителем языка.**
Обязательно проверьте перед запуском.

## Сложность

Две строки в `cfg()` — этого хватает, чтобы крутить всю кривую:

```js
approach: Math.max(7, 15 - 0.35 * (lv - 1)),   // сек, пока ведьма идёт по дороге
hunt:     Math.min(100, 50 + 3 * (lv - 1))     // стартовая скорость погони
```

Плюс три константы рядом с игровым циклом: пока ведьма в доме, первые
`RUSH_GRACE` секунд она идёт как обычно, дальше разгоняется (`HUNT_RUSH`) и
всё дальше тянется рукой (`REACH_GROW`). Так наказывается стояние на месте:
без единого хода ловят примерно на 47-й секунде, а нормальной игре это
не мешает.

## Конкурс и трейлер

В `dist/index.html`, в начале блока `<script>`, лежат три строки, которые
меняются без правки остального кода:

```js
var TRAILER_URL = 'https://www.youtube.com/watch?v=...';  // кнопка «ТРЕЙЛЕР»
var RELEASE = 'в кино с 5 ноября';                        // подпись к дате
var INSTA = 'qaratuyin_film';                             // аккаунт в текстах и на постере
```

Кнопка «УЧАСТВОВАТЬ В КОНКУРСЕ» на экране поимки собирает постер с результатом
и открывает системное «Поделиться» — именно через выложенный постер и его QR
приходят новые игроки. Текст, который уходит вместе с картинкой, собирается
функцией `shareText()` там же.

## Адрес игры (QR и ссылка в тексте результата)

Игра опубликована на GitHub Pages из ветки `main`:
`https://izibizproduction.github.io/qara-tuyin-game/` — этот же адрес зашит в
константу `GAME_URL` в начале блока `<script>` и нарисован в QR на постере
результата (`assets/qr.webp`).

Меняете адрес — поменяйте `GAME_URL` и перерисуйте QR:

```bash
python -c "import segno; segno.make('<новый адрес>', error='m').save('qr.png', scale=10, border=2, dark='#0a0e14', light='#ffffff')"
convert qr.png -resize 296x296 -quality 92 assets/qr.webp
```

## Вес

| что                          | сколько   |
|------------------------------|-----------|
| `index.html`                 | 68 КБ     |
| картинки + QR                | 448 КБ    |
| **блокирующая загрузка**     | **510 КБ**|
| музыка (грузится фоном)      | 1.86 МБ   |

Исходники весили 43.6 МБ — задники по 8 МБ каждый пережаты из PNG 2160×3840
в WebP 810×1440, музыка переведена в моно 64 kbps. Музыка не задерживает
старт: она начинает грузиться только после того, как показалось меню.

## Кинотеатры во вкладке «Билеты»

Список лежит в `index.html` в массиве `CINEMAS`: страна → группа (город или
«сети») → залы. У зала поле `kind`:

| kind     | как показывается                         |
|----------|------------------------------------------|
| `online` | прямая ссылка на страницу фильма         |
| `site`   | афиша кинотеатра или сети                |
| `wa`     | бронь по WhatsApp (бейдж WhatsApp)       |
| `box`    | только касса (бейдж «касса»)             |

Сейчас стоят афиши казахстанских сетей и агрегаторов. Когда «Қара Түйін»
появится в расписании, замените `url` на страницу фильма и поставьте
`"kind": "online"` — больше ничего менять не нужно.

## Дата премьеры и обратный отсчёт

`var PREMIERE = new Date(2026, 10, 5);` — месяцы в JS считаются с нуля,
поэтому `10` это ноябрь. Эта же дата нарисована на `assets/release_date.webp`.
